# BlogVerse

Full-stack blogging application with React frontend and Node.js backend.

## Project Structure

- `client/` - React frontend application
- `server/` - Node.js/Express backend API

## Getting Started

### Prerequisites

- Node.js >= 16
- npm or yarn

### Installation

```bash
# Install all dependencies
npm run install:all

# Or using workspaces
npm install
```

### Development

```bash
# Run both client and server
npm run dev

# Run client only
npm run dev:client

# Run server only
npm run dev:server
```

### Build

```bash
# Build both
npm run build

# Build client only
npm run build:client

# Build server only
npm run build:server
```
